# GreenMove Enterprise: Movilidad Universitaria Inteligente

*GreenMove* es una solución tecnológica diseñada para optimizar los traslados diarios de la comunidad universitaria. A través de un sistema de carpooling (uso compartido de autos), buscamos reducir la huella de carbono, disminuir el tráfico en los alrededores de los campus y fomentar una cultura de colaboración entre estudiantes.

## 🚀 Propuesta de Valor

* *Sustentabilidad:* Mitigación directa de emisiones de $CO_2$ mediante la optimización de asientos vacíos.
* *Comunidad:* Conexión segura entre alumnos con rutas similares.
* *Gamificación:* Sistema de "EcoPuntos" y medallas que incentivan el uso constante de la plataforma.
* *Seguridad:* Verificación de usuarios mediante códigos PIN únicos durante el proceso de abordaje.

## 🛠️ Tecnologías Utilizadas

El prototipo actual ha sido desarrollado utilizando un stack web ligero y de alto rendimiento:

* *HTML5:* Estructura semántica de la aplicación.
* *CSS3:* Diseño responsivo con CSS Grid/Flexbox, variables de color (estética tipo Material Design) y animaciones clave (keyframes).
* *JavaScript (ES6+):* Lógica funcional para la gestión de estados, manipulación del DOM y simulación de base de datos en tiempo real.
* *Google Maps Embed API:* Integración de geolocalización para la visualización de trayectos.

## 📱 Funcionalidades Principales

### Para Pasajeros:

* *Buscador de Rutas:* Filtra conductores cercanos basados en destino y horario.
* *Sistema de Solicitud:* Envío de peticiones de abordaje con confirmación.
* *Canje de Beneficios:* Intercambio de EcoPuntos acumulados por servicios dentro del campus (café, estacionamiento, etc.).

### Para Conductores:

* *Gestión de Rutas:* Publicación rápida de trayectos con capacidad de pasajeros ajustable.
* *Bitácora de Usuarios:* Visualización en tiempo real de alumnos que han solicitado un lugar en su auto.
* *Verificación:* Validación de pasajeros mediante el sistema de pines de seguridad.

## ⚙️ Cómo ejecutar el proyecto

1. Clona este repositorio o descarga el archivo index.html.
2. Abre el archivo index.html en cualquier navegador web moderno (Chrome, Edge, Safari o Firefox).
3. *Prototipo:* Al ser una aplicación front-end pura, puedes interactuar directamente con el flujo de inicio de sesión ingresando cualquier nombre y seleccionando un perfil para probar las funcionales
